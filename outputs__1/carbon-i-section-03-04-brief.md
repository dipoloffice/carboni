# CARBON-i 섹션 03/04 구현 기준

작성일: 2026-05-13

## 적용 범위

- `version1`, `version2`, `version3` 공통 적용
- 메인 랜딩페이지의 fullpage snap-scroll 안에서 이어지는 3번째, 4번째 전환 섹션
- PPT의 `3PAGE`, `4PAGE`는 별도 URL 페이지가 아니라 메인 화면 안의 섹션 단위로 해석한다.

## Section 03: 카본아이 뉴스

PPT 9-10페이지 기준.

핵심 역할:

- 카본아이에서 제공하는 배출권거래제 관련 뉴스, 영상, 행사, 법령/지침, 정책 콘텐츠 허브
- 상단 공통 헤더와 메뉴 구조는 기존 디자인 시스템을 유지한다.
- `뉴스` 키워드는 포인트 컬러로 강조한다.

구성 기준:

- 좌측 또는 주요 영역: 탭형 게시글 리스트
- 탭: `데이터`, `전망`, `보고서`, `정책·알림`
- 게시글 리스트는 카테고리 태그, 제목, 작성일을 가진다.
- 최신순 정렬을 전제로 하며, 클릭 시 상세 페이지 이동 가능성을 고려한다.
- 우측 또는 보조 영역: 고정 썸네일 카드 4개
- 카드: `카본아이 온에어`, `행사 정보`, `법령/지침`, `정책 바로알기`
- 카드에는 고정 썸네일, 제목, 날짜, 무료 이용자 노출 가능 여부 또는 신청 기간 정보를 표시한다.

관리 기준:

- 관리자에서 썸네일 이미지, 행사명, 날짜, 신청 기간, 노출 문구를 수정할 수 있어야 한다.
- 향후 영상 썸네일 및 영상 링크 등록 가능성을 고려한다.

## Section 04: 카본아이 확장 서비스

PPT 11-14페이지 기준.

핵심 역할:

- CARBON-i가 단순 시황 정보 플랫폼이 아니라 기업 맞춤형 탄소시장 서비스로 확장된다는 인상을 준다.
- 프리미엄 서비스 전환 유도 영역으로 사용한다.

서비스 카드:

- `EU-ETS`
- `국제감축사업`
- `탄소자산운용`
- `감축전략수립`

카드 디자인 기준:

- 세로형 윈도우 카드 구조
- 상단 대표 썸네일 이미지는 고정
- 카드별 카테고리 컬러 바를 둔다.
- 서비스명과 핵심 설명을 명확히 분리한다.
- 카드 hover 시 과하지 않게 떠오르는 느낌을 준다.
- 카드별 설명 문구는 3개까지 등록 가능하며, 썸네일은 고정하고 하단 설명만 슬라이드 전환한다.
- 슬라이드 인디케이터를 제공한다.

서비스별 문구 방향:

- `EU-ETS`: EUA 규제·정책 분석, 시장 전망 리포트, 구매·보유·이전·정산 통합 서비스
- `국제감축사업`: 파리협정 6조, CORSIA/VCM, COP/SB 국제회의 및 정책 동향
- `탄소자산운용`: 배출량 관리, 할당 최적화, 배출권 거래 전략, 과부족 분석
- `감축전략수립`: 기후 시나리오, 감축 경로, MACC, 투자 우선순위, 재무 영향 분석

추가 고려:

- 향후 `국제감축사업`과 `VCM`이 분리될 수 있으므로 카드 수 변경이 가능한 구조로 유지한다.
- 1920px 기준, 최소 1280px 화면에서 안정적으로 보이도록 한다.
- 모바일에서는 카드가 세로로 쌓이며, fullpage snap-scroll보다 내용 가독성을 우선한다.
